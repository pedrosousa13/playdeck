# Capabilities matrix

Capabilities come from the core `PlayerCapabilities` contract. Each control
below reads one capability (or, for `Controls`, several) and appears only when
that capability resolves `available`; while `unknown` or `unavailable` it
renders nothing.

| Component                 | Gating capability                                     | Renders when                          |
| ------------------------- | ----------------------------------------------------- | ------------------------------------- |
| `Player.PlayButton`       | — (provider presence)                                 | always (not capability-gated)         |
| `Player.MuteButton`       | `setVolume`                                           | `setVolume` is `available`            |
| `Player.VolumeSlider`     | `setVolume`                                           | `setVolume` is `available`            |
| `Player.SeekSlider`       | `seek`                                                | `seek` is `available`                 |
| `Player.FullscreenButton` | `fullscreen`                                          | `fullscreen` is `available`           |
| `Player.PipButton`        | `pictureInPicture`                                    | `pictureInPicture` is `available`     |
| `Player.AirPlayButton`    | `airPlay`                                             | `airPlay` is `available`              |
| `Player.Time`             | — (display)                                           | always                                |
| `Player.Controls`         | `seek`, `setVolume`, `fullscreen`, `pictureInPicture` | container; children gate individually |

`airPlay` reports whether the engine exposes a route picker, not whether there
is anything to cast to: it resolves `available` when WebKit's
`webkitShowPlaybackTargetPicker` exists and the media does not opt out via
`x-webkit-airplay="deny"` or `disableRemotePlayback`. So `Player.AirPlayButton`
renders nothing outside Safari and iOS, but inside them it renders even when no
receiver is on the network, and opens an empty picker.

`selectTextTrack` gates `Player.CaptionsButton` — see the Captions docs.

`setPlaybackRate` and `selectQuality` have no dedicated primitive, and are
composed by the consumer instead — see the **Reference example**, whose settings
menu builds a playback-rate group and a quality group over
`Player.SettingsMenu`/`Player.MenuRadioGroup`, each gated on its own capability.
`selectQuality`'s ladder comes from `PlayerState.qualities`; only the hls.js
engine populates it. `customControls` gates no shipped control.
