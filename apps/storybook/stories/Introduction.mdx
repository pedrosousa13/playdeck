# Playdeck workbench

Headless player primitives staged in isolation. Every story renders under a
mock `Player.Root` backed by an inert provider, so any `PlayerState` and
capability set can be dialed in deterministically — with no media, network, or
SDKs. Real playback lives right here too, under the `Real playback/Providers`
stories (native MP4, HLS, live, YouTube, Vimeo) and the `Fixtures/PlayerFixture`
stories the e2e suite drives — those hit the network and are excluded from the
deterministic test run (tagged `!test`).

The **Overview/Reference example** page documents one composed player built only
from public exports — the runnable proof that the primitives are sufficient, and
the target the accessibility work is pointed at.

## Story conventions

- Import primitives as `import * as Player from '@playdeck/react'`; title under
  `Player/<Component>`.
- Dial state with the `ready(capabilityOverrides, statePatch)` helper from
  `stories/support.tsx`. Its capability base is derived from the real core
  contract (`createInitialPlayerState().capabilities`) and guarded by
  `support.contract.test.ts`, so stories can only stage states the real
  controller accepts.
- Each story runs as a Vitest browser test with an axe check
  (`a11y.test: 'error'`) and must issue **zero external requests** (enforced by
  `.storybook/vitest.setup.ts`).
- Prove interactions with a `play` function (see `Player/ActivationButton`).
- Give every story a JSDoc block above its export. Autodocs renders it as the
  story's description, and without one the page shows a bare name over a canvas
  — which is the reader's only cue for what a case is and why it exists. Say
  what a reader cannot infer from the story name; one line that does is worth
  more than three that restate it.
- **The one exemption is `Fixtures/PlayerFixture`.** Its stories are Playwright
  targets addressed by story ID from `e2e/`, not documentation, and each is
  described by the spec that drives it. It is tagged `!test` and excluded from
  the deterministic run. Nothing else is exempt.
