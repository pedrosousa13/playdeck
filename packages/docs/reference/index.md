Every published package, from the README that ships inside its own npm tarball.

New to the library? [Start](../start.md) is one package, one composition, and what each provider needs.

Published under `@playdeck/`.

- [`@playdeck/core`](./core.md) — Framework-neutral player state, commands, events and provider contract for Playdeck.
- [`@playdeck/provider-hls`](./provider-hls.md) — HLS provider for Playdeck, over hls.js or the browser’s native HLS.
- [`@playdeck/provider-native`](./provider-native.md) — HTMLMediaElement provider for Playdeck: progressive files and native HLS.
- [`@playdeck/provider-vimeo`](./provider-vimeo.md) — Vimeo player SDK provider for Playdeck.
- [`@playdeck/provider-wistia`](./provider-wistia.md) — Wistia player SDK provider for Playdeck.
- [`@playdeck/provider-youtube`](./provider-youtube.md) — YouTube IFrame Player API provider for Playdeck.
- [`@playdeck/react`](./react.md) — Headless, composable React 19 media player primitives with capability-aware providers.
